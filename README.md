# Game of Life

Классическая клеточная автоматная игра «Жизнь» Джона Конвея с интерактивным управлением и предустановленными паттернами.

## Управление

| Клавиша | Действие                                      |
|---------|-----------------------------------------------|
| **Пробел** | Старт / Пауза симуляции                     |
| **R**      | Сбросить поле (очистить все клетки)         |
| **T**      | Случайное распределение клеток              |
| **1**      | Паттерн: Glider (планер)                    |
| **2**      | Паттерн: Light Space Ship (лёгкий корабль)  |
| **3**      | Паттерн: Middle Space Ship (средний корабль)|

## Как запустить

1. Убедитесь, что у вас установлен Python 3.
2. Установите необходимые зависимости (если используются):

```bash
pip install -r requirements.txt
```

3. Запустите игру:

```bash
python main.py
```

4. Используйте клавиши управления для взаимодействия с симуляцией.

## Правила игры

- Мир представляет собой сетку клеток, каждая из которых может быть живой или мёртвой.
- Состояние клетки в следующем поколении определяется количеством живых соседей:
  - Живая клетка с 2–3 живыми соседями выживает.
  - Мёртвая клетка с 3 живыми соседями оживает.
  - В остальных случаях клетка умирает или остаётся мёртвой.

## Паттерны

- **Glider (1)** — движущаяся фигура, перемещающаяся по диагонали.
- **Light Space Ship (2)** — быстрый космический корабль, движущийся горизонтально.
- **Middle Space Ship (3)** — более крупный космический корабль.
